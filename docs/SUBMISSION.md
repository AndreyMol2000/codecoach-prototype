## Репозиторий GitHub

Адрес для сдачи: **https://github.com/AndreyMol2000/codecoach-prototype**. Если по этой ссылке уже видны исходники и README, повторно создавать репозиторий не нужно. Дальнейшие инструкции пригодятся при самостоятельной повторной публикации или переносе проекта.

Если репозиторий ещё не опубликован, создайте на GitHub репозиторий `codecoach-prototype` с видимостью **Public**. Не добавляйте через форму начальный README, лицензию и .gitignore: они уже есть в проекте.

Проще всего загрузить содержимое папки проекта через страницу репозитория **uploading an existing file**. В корне должны находиться `package.json`, `README.md`, `server.mjs` и папки `public`, `test`, `docs`. Не загружайте содержащую их дополнительную папку, архив вместо исходников, исходные DOCX/PPTX и экспортированные результаты участников.

Через Git, если локальный репозиторий ещё не создан:

```sh
git init -b main
git add .
git -c user.name="Andrey Molchanov" -c user.email="codecoach-author@users.noreply.github.com" commit -m "Build CodeCoach learning prototype"
```

Адрес ниже нужно заменить на реальный адрес своего созданного репозитория:

```sh
git remote add origin https://github.com/YOUR_LOGIN/codecoach-prototype.git
git push -u origin main
```

Если локальный репозиторий уже подготовлен, повторять `git init` и `git commit` не нужно. Используйте адрес, показанный GitHub. Во время входа не вставляйте токены в переписку, исходники или URL remote. Используйте штатную авторизацию Git/GitHub.

После публикации откройте ссылку в окне без входа в аккаунт и убедитесь, что видны исходники и README. Скачайте ZIP и запустите по инструкции.
