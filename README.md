# CodeCoach

Работающий локальный прототип наставника по JavaScript для начинающих программистов. Ученик пишет код, запускает тесты и получает помощь по шагам: от вопроса до решения с объяснением. Затем решает похожую задачу без подсказок.

Автор учебного проекта: **Молчанов Андрей Владимирович**. Дисциплина: «Стартап-экосистемы». Домашнее задание: «Разработка проекта с помощью ИИ-агента». Агент разработки: **OpenAI Codex**.

Публичный репозиторий: [AndreyMol2000/codecoach-prototype](https://github.com/AndreyMol2000/codecoach-prototype).

## Какую гипотезу проверяем

Пошаговые подсказки помогают новичку исправить ошибку в поиске максимума и самостоятельно применить тот же принцип для поиска минимума. Проверяем учебный цикл, выбранный из концепции CodeCoach. Эффективность конкретной LLM этот прототип пока не проверяет.

Порог пилота, выбранный до сбора данных: минимум 5 участников, из них хотя бы 60% решают первую задачу за 10 минут без открытия готового ответа, а затем решают вторую без подсказок. Это предварительный критерий команды, а не уже полученный результат. Подробнее: [план проверки](docs/HYPOTHESIS.md).

## Быстрый запуск

Нужен **Node.js 22 или новее** и современный браузер: Chrome, Edge, Firefox или Safari с поддержкой Web Workers. Внешние библиотеки, npm install, API-ключи и регистрация не нужны.

1. Скачайте ZIP этого репозитория кнопкой GitHub **Code → Download ZIP** и распакуйте.
2. Откройте терминал в папке, где находится `package.json`.
3. Запустите:

```sh
node server.mjs
```

4. Откройте **http://127.0.0.1:3000**.

Альтернатива: `npm start`. Остановка сервера: `Ctrl+C`. Не открывайте `index.html` двойным кликом: ES-модулям нужен локальный HTTP-сервер.

Если установлен Git, вместо скачивания ZIP можно выполнить:

```sh
git clone https://github.com/AndreyMol2000/codecoach-prototype.git
cd codecoach-prototype
node server.mjs
```

Если порт занят, в PowerShell:

```powershell
$env:PORT = '3001'
node server.mjs
```

В macOS/Linux:

```sh
PORT=3001 node server.mjs
```

Откройте `http://127.0.0.1:3001`. Хранилище привязано к адресу, порту и профилю браузера: используйте один и тот же адрес для продолжения сессии.

## Демонстрация за 3 минуты

1. На главной нажмите **«Начать с первой задачи»**.
2. В задаче «Максимум в массиве» нажмите **«Проверить код»**. Стартовое `let max = 0` проходит 3 из 6 тестов и даёт неверные ответы для отрицательных чисел.
3. Нажмите **«Получить первую подсказку»**. Наставник задаст вопрос и покажет неудачный пример. Первые три уровня помощи не выдают готовый код.
4. Замените `let max = 0;` на `let max = numbers[0];`. Снова проверьте: 6 из 6 тестов, 80 XP при одной подсказке.
5. Нажмите **«Проверить себя без подсказок»**, напишите `findMin` и запустите тесты. В этой задаче нет помощи наставника.
6. Откройте **«Результаты пилота»**: видны время до первого решения, попытки, подсказки и перенос навыка. Заполните рефлексию и выгрузите JSON.

Для проверки самого запуска также можно использовать `const findMax = numbers => Math.max(...numbers);`. Любое решение проходит фактические тесты, совпадение с эталонной строкой не требуется. Для живого эксперимента не показывайте ученикам эти ответы заранее.

Полный текст выступления: [DEMO.md](docs/DEMO.md).

## Что работает

- Учебный маршрут и редактор с сохранением черновика, номерами строк и сочетанием `Ctrl/Cmd+Enter`. Клавиша `Tab` вставляет отступ, `Escape` переводит фокус к кнопке проверки.
- Четыре задачи и 24 тестовых случая: максимум, минимум, чётные числа, сумма положительных.
- Выполнение пользовательского JavaScript, сравнение реальных результатов, обработка синтаксических ошибок и исключений.
- Четыре уровня контекстной помощи. Для ошибок синтаксиса, исключений и зависших циклов используются отдельные ветки подсказок.
- Остановка бесконечного цикла через 1,8 секунды без блокировки основного интерфейса. Резервный таймер оболочки — 3,8 секунды. Фоновая вкладка и загруженный браузер могут задержать таймеры.
- XP один раз за первое успешное решение: 100 / 80 / 60 / 40 / 20 в зависимости от количества открытых уровней помощи. Историческая награда сохраняется при повторных запусках.
- Рекомендация следующего упражнения, зависящая от прохождения. Это простой маршрут на правилах, не полноценная адаптивная модель.
- Локальные анонимные сессии участников, журнал действий, рефлексия и JSON-экспорт для проверки гипотезы.
- Адаптивная вёрстка, клавиатурная навигация, текстовые статусы тестов.

## Наставник и границы прототипа

**Наставник работает на правилах, без вызова внешней AI-модели.** Он выбирает ветку по результатам настоящего запуска и выдаёт заранее подготовленные учебные подсказки. Это прямо указано в интерфейсе. Не заявляем, что он произвольно анализирует любой код или ведёт свободный диалог.

Задача на перенос доступна из списка сразу, но в успешный сценарий эксперимента попадёт только если открыта после решения первой задачи. В ней отключены подсказки. Полный исходный код проекта публичен: это тренажёр, не защищённая экзаменационная система. Тесты покрывают ограниченный набор входов и не доказывают корректность на всех возможных данных.

Проверяются синхронные функции над конечными числами. Асинхронные решения и сторонние библиотеки не поддерживаются. Не реализованы аккаунты, платежи, серверная база, streak, полноценное дерево навыков и B2B-функции. Они не нужны для выбранной проверки.

## Техническое устройство

```text
server.mjs                 HTTP-сервер Node.js, только встроенные модули
public/index.html          Точка входа
public/app.js              Экраны, редактор, события и экспорт
public/style.css           Адаптивный интерфейс
public/tasks.js            Условия, стартовый код, тесты и учебные подсказки
public/runner-core.js      Компиляция решения и выполнение тестовых случаев
public/runner.js           Изолированный iframe, Worker и таймер остановки
public/learning.js         Подсказки, XP, рекомендации и метрики пилота
public/store.js            Сессии и localStorage
test/                      Автоматические проверки логики и HTTP
docs/                      План эксперимента, выступление и сдача
```

Код ученика выполняется **в Worker внутри sandbox-iframe с отдельным непрозрачным origin**. CSP отключает сетевые подключения и загрузку внешних ресурсов внутри этой среды. Сервер не исполняет присланный код и слушает только `127.0.0.1`. В DOM пользовательский текст вставляется с экранированием.

Это изоляция учебного локального прототипа, не сертифицированная среда запуска враждебного кода. Лимит времени не ограничивает объём памяти: не запускайте программы, намеренно исчерпывающие ресурсы браузера. Для публичного многопользовательского сервиса потребуется отдельная архитектура выполнения.

## Данные и секреты

- У сервиса нет API-ключей, паролей и токенов. Зависимости и внешние шрифты не загружаются.
- Черновики, попытки и ответы хранятся только в `localStorage` текущего браузера. Данные на сервер не отправляются. При недоступности хранилища показывается предупреждение, сессия продолжает работать в памяти.
- JSON содержит код решений и временные отметки действий. Не вводите в редактор реальные секреты и персональные данные. Перед передачей выгрузки получите согласие участников.
- «Новый участник» создаёт отдельную пустую сессию, сохраняя предыдущие. Все локальные данные можно удалить на экране результатов с подтверждением.
- Файлы выгрузок, `.env` и зависимости исключены из Git через `.gitignore`. Материалы исходного проекта и переписка с агентом в репозиторий не включены.

node --test
