# Как запустить CodeCoach с n8n и Qwen3

Инструкция для Windows x64. CodeCoach состоит из трёх сервисов: веб-чата, n8n и локальной модели Qwen3. Скрипт запускает их вместе.

## Если проект уже настроен на этом компьютере

1. Откройте папку проекта — ту, где лежат `N8N_START.md`, `README.md` и папка `codecoach-n8n`. Для основной рабочей копии это папка `codecoach-prototype`.
2. В адресной строке Проводника введите `powershell` и нажмите Enter. PowerShell откроется в нужной папке.
3. Выполните команду:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\codecoach-n8n\scripts\start.ps1
```

4. Дождитесь запуска сервисов. Веб-чат откроется автоматически, но n8n и модель могут ещё загружаться. Обычно стоит подождать около минуты; время зависит от компьютера.
5. Откройте **http://127.0.0.1:3010** и отправьте вопрос, например: «Чем отличается return от console.log в функции JavaScript?».

Если workflow уже импортирован и опубликован, повторно настраивать n8n не нужно. Сообщение скрипта `First launch` напоминает о настройке только для первого запуска.

`ExecutionPolicy Bypass` в этой команде действует только для запускаемого процесса PowerShell. Постоянные настройки Windows не меняются.

## Если устанавливаете проект с GitHub впервые

### 1. Подготовьте компьютер

Понадобятся:

- Windows x64;
- Node.js версии 22 или 24 с доступными командами `node` и `npm`;
- Git, если будете скачивать проект командой `git clone`;
- интернет для установки и несколько гигабайт свободного места для модели и зависимостей.

Проверьте Node.js и npm в PowerShell:

```powershell
node --version
npm.cmd --version
```

После установки Node.js откройте новое окно PowerShell, чтобы оно увидело команды.

### 2. Скачайте проект

Откройте PowerShell в папке, где хотите хранить проект, и выполните:

```powershell
git clone https://github.com/AndreyMol2000/codecoach-prototype.git
Set-Location .\codecoach-prototype
```

Если Git не установлен, откройте репозиторий в браузере, нажмите **Code → Download ZIP**, распакуйте архив и откройте PowerShell в распакованной папке рядом с `N8N_START.md`.

Дальше все команды выполняются из корня репозитория. Внутри него есть ещё одна папка `codecoach-n8n` — она содержит приложение и скрипты.

### 3. Установите n8n и модель

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\codecoach-n8n\scripts\setup.ps1 -RuntimeRoot "$env:USERPROFILE\Documents\Codex\work\n8n-agent-runtime"
```

Скрипт скачает llama.cpp, модель Qwen3-1.7B Q8_0 и зависимости n8n. Только веса модели занимают около 1,83 ГБ. Установка может занять заметное время. Дождитесь сообщения `Setup complete`.

Скрипт создаст локальный файл `codecoach-n8n/.local-runtime.json` с путями к установленным компонентам. На другом компьютере установку нужно выполнить заново. При обычном повторном запуске этот шаг пропускается.

### 4. Запустите сервисы

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\codecoach-n8n\scripts\start.ps1
```

Дождитесь загрузки, затем откройте **http://127.0.0.1:5678**.

### 5. Настройте n8n один раз

1. В браузере завершите первоначальную настройку локального владельца n8n. Сохраните выбранные учётные данные: они понадобятся для последующего входа в редактор.
2. Создайте новый workflow и откройте меню с тремя точками в правом верхнем углу редактора.
3. Выберите **Import from File…** и укажите файл `codecoach-n8n/codecoach-workflow.json` из скачанного проекта.
4. После импорта откроется **CodeCoach · Qwen + web chat** из 13 нод.
5. Проверьте ноду **07 · Qwen real LLM call**: адрес должен быть `http://127.0.0.1:8081/v1/chat/completions`. API-ключ для локальной модели не нужен.
6. Нажмите **Publish / Опубликовать**. Веб-чат использует production webhook, поэтому одного тестового запуска через **Execute Workflow** недостаточно.

Способ импорта через меню редактора описан в [официальной справке n8n](https://docs.n8n.io/workflows/export-import/).

### 6. Проверьте работу

Откройте **http://127.0.0.1:3010**, выберите глубину помощи **2 · Объяснение причины**, введите вопрос про `return` и `console.log` и нажмите **Отправить**. Дождитесь ответа: на медленном компьютере это может занять до двух минут.

В редакторе n8n откройте **Executions**. Успешное выполнение и результат ноды 07 подтверждают, что запрос прошёл через workflow и модель.

После первоначальной настройки для следующих запусков достаточно команды из начала инструкции.

## Адреса сервисов

| Что открыть | Адрес |
|---|---|
| Пользовательский веб-чат | http://127.0.0.1:3010 |
| Редактор n8n | http://127.0.0.1:5678 |
| Проверка модели | http://127.0.0.1:8081/health |

Эти адреса работают на компьютере, где запущен проект. Сервисы работают в фоне; закрытие вкладки браузера их не останавливает.

## Если не запускается

**Команда `node` или `npm` не найдена.** Установите Node.js 22 или 24 и заново откройте PowerShell.

**Скрипт пишет `Run scripts/setup.ps1 first`.** В проекте нет локальных настроек. Выполните шаг установки, затем повторите запуск.

**Чат открылся, но не отвечает.** Подождите загрузки сервисов и проверьте их состояние:

```powershell
Invoke-RestMethod http://127.0.0.1:3010/api/status | Format-List
```

Ожидаемые значения: `n8n : True` и `llm : True`. Если `n8n` имеет значение `False`, редактор n8n ещё не доступен. Если `llm` имеет значение `False`, не готов сервер модели. Если не открывается сам адрес проверки, не запущен веб-сервер.

**Оба значения `True`, но n8n не возвращает ответ.** Проверьте, что workflow импортирован и опубликован. Откройте последний запуск в **Executions**: там будет видна нода с ошибкой.

**Нужно посмотреть журнал.** Из корня проекта выполните:

```powershell
$codeCoachConfig = Get-Content .\codecoach-n8n\.local-runtime.json -Raw | ConvertFrom-Json
Get-Content -LiteralPath (Join-Path $codeCoachConfig.statePath 'n8n.err.log') -Tail 30
Get-Content -LiteralPath (Join-Path $codeCoachConfig.statePath 'llama.err.log') -Tail 30
```

**Проверка логики проекта без запуска модели:**

```powershell
node --test .\codecoach-n8n\test\agent.test.mjs
```

Эти тесты проверяют обработку данных. Полный путь через n8n и Qwen проверяется вопросом в веб-чате.
