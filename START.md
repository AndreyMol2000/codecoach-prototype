# Как запустить CodeCoach

Основной проект — тренажёр JavaScript с редактором, тестами и пошаговыми подсказками. Он открывается по адресу **http://127.0.0.1:3000**.

## 1. Подготовьте Node.js

Нужен Node.js версии 22 или новее. После установки откройте PowerShell и проверьте:

```powershell
node --version
```

Если команда не найдена, установите Node.js и откройте новое окно PowerShell.

## 2. Скачайте проект

Если установлен Git, выполните в папке для ваших проектов:

```powershell
git clone https://github.com/AndreyMol2000/codecoach-prototype.git
Set-Location .\codecoach-prototype
```

Без Git: откройте репозиторий на GitHub, нажмите **Code → Download ZIP** и распакуйте архив. В адресной строке распакованной папки введите `powershell` и нажмите Enter.

Нужна папка, где лежат `package.json`, `server.mjs`, `README.md` и папка `public`. Если проект уже скачан, просто откройте PowerShell в этой папке.

Для рабочей копии, подготовленной в папке `стартап`, можно перейти туда так:

```powershell
Set-Location -LiteralPath "$env:USERPROFILE\Documents\ChatGPT\стартап\codecoach-prototype"
```

## 3. Запустите сервер

```powershell
node server.mjs
```

Для основного тренажёра `npm install` не требуется: сервер использует встроенные модули Node.js. API-ключи не нужны.

Оставьте окно PowerShell открытым: в нём работает сервер.

## 4. Откройте приложение

Перейдите в браузере на **http://127.0.0.1:3000**.

Не открывайте `public/index.html` двойным кликом. Приложению нужен HTTP-сервер, запущенный предыдущей командой.

## 5. Проверьте сценарий

1. Нажмите **«Начать с первой задачи»**.
2. В задаче «Максимум в массиве» нажмите **«Проверить код»**. В стартовом решении есть ошибка: `let max = 0`.
3. Откройте подсказку, исправьте решение и снова запустите тесты.
4. После успешного решения перейдите к задаче на поиск минимума без подсказок.

В основном тренажёре наставник выбирает подготовленные подсказки по результатам тестов. Чтобы получать ответы Qwen3 в панели **«Чат по задаче»**, запустите дополнительные сервисы по инструкции ниже.

## Остановка и повторный запуск

Для остановки нажмите **Ctrl+C** в окне PowerShell, где запущен сервер.

При следующем запуске откройте ту же папку и снова выполните `node server.mjs`. После этого откройте тот же адрес и профиль браузера, чтобы продолжить сохранённую сессию.

## Если порт 3000 занят

Запустите сервер на другом порту в этом же окне PowerShell:

```powershell
$env:PORT = '3001'
node server.mjs
```

Откройте **http://127.0.0.1:3001**. Прогресс в браузере привязан к адресу и порту, поэтому сессия на новом порту будет отдельной.

## Проверка тестов

Откройте второе окно PowerShell в корне репозитория:

```powershell
node --test
```

В репозитории проверяются основной тренажёр и обработка данных дополнительного n8n-агента. Для полного сценария n8n с моделью нужен отдельный запуск.

## Дополнительный сценарий: n8n и Qwen3

В папке `codecoach-n8n` находится отдельный веб-чат с настоящими ответами локальной Qwen3 через workflow n8n из 13 нод. Адрес чата — **http://127.0.0.1:3010**, редактора n8n — **http://127.0.0.1:5678**.

У него свои зависимости и первоначальная настройка. Следуйте отдельной инструкции: **[запуск n8n и Qwen3](N8N_START.md)**.
