# Разработка с помощью ИИ-агента

Инструмент: **OpenAI Codex**. Исходные материалы: описание и презентация CodeCoach, предоставленные автором. Эта запись описывает выполненный объём работы; она не является вымышленным журналом командных встреч.

## Постановка задачи

Собрать локальный прототип CodeCoach для проверки одной существенной гипотезы: переход от ошибки через постепенные подсказки к самостоятельной похожей задаче. Требования: реальные запуски JavaScript, понятная обратная связь, сохранение результатов, README и материалы предзащиты. Не использовать реальные пароли и API-ключи.

## Решения при реализации

- Один язык — JavaScript. Основная пара задач — максимум и минимум в массиве.
- Наставник на правилах, явно обозначенный в интерфейсе. Он реагирует на результаты запуска. Интеграция LLM не имитируется.
- Стандартный Node.js и HTML/CSS/JavaScript без установки зависимостей.
- Пользовательский код запускается в изолированной браузерной среде с таймером остановки.
- Первое успешное решение фиксируется отдельно от повторных запусков. Награду нельзя накапливать повторной проверкой одной задачи.
- Критерий эксперимента учитывает порядок прохождения и глубину помощи на момент решения.

## Проверка результата

Автоматические проверки проверяют фактические ответы функций, ошибки, подсказки, прогресс и метрики. Ручная проверка в браузере охватывает основной учебный сценарий, бесконечный цикл и сохранение. Фактический статус проверок записан в CHECKS.md.

## Что должен сделать автор перед сдачей

Самостоятельно пройти сценарий и убедиться, что понятны исходная ошибка, исправление и ограничения. Если проект выполняется командой, совместно обсудить постановку задачи и результаты и записать реальный вклад участников. Пользовательский пилот провести отдельно; разработка прототипа не заменяет сбор данных.
